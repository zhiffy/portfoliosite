# Claude Design Preview

This branch exists only so Claude Design/local previews can open the site without production rewrites.

- Production branch: main, with clean routes like /works/after-ophelia/.
- Claude branch: claude-design-preview, with direct files like after-ophelia.html and relative asset paths like assets/... so Claude can render CSS/images.
- Do design, copy, layout, and asset edits here as needed.
- When the edits are ready, ask Codex to bring the Claude Design edits back to main while keeping main's clean production routes.

Do not deploy this branch as the public production site unless you intentionally want direct .html links.
