PRESS IMAGES
============

Drop your selected high-resolution press images into this folder using the
filenames listed below. The press kit PDF references these exact filenames,
so journalists can locate each image directly.

Specs
-----
- Format: JPG (preferred) or PNG
- Long edge: at least 3000px
- Color space: sRGB
- File size: under 5 MB each is plenty
- No watermarks
- Filename exactly as listed above

Total bundle size target: under 30 MB. If individual files run large, compress
to ~80 percent quality with mozjpeg or imageoptim before adding.

Credits
-------
Default credit line for any image: "Courtesy the artist Shavonne Wong"
For images shot by another photographer, ensure the credit line is supplied
to the studio so it can be updated in the press kit PDF on the next refresh.
